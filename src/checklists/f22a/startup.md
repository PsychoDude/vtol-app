# F-22A Raptor Startup Checklist

**Right-side Panels:**

1. Start BATTERY
2. Close CANOPY

**Left-side Panels:**

3. Set Lights AS REQUIRED
4. Start APU and confirm RPM NOMINAL
5. Start RIGHT ENGINE and confirm RPM NOMINAL
6. Start LEFT ENGINE and confirm RPM NOMINAL
7. Set MFCDs AS REQUIRED
8. Shut down APU

**Right-side Panels:**

9. Check Microphone ON
10. Check Master Arm OFF
11. Contact Tower for takeoff

> **CAUTION:**

<div class="border-s-4 border-red-700 ps-4 my-5 flex flex-col gap-5">
<p>Nominal refers to the RPM being in the green zone of the dial. Starting the engine before the APU is fully spun up will lead to ignition failure.</p>

<p>In the event of ignition failure, shut down engine, and confirm APU RPM NOMINAL. Once NOMINAL, repeat step 5.</p>
</div>
